# Runtime dependencies for the Xenosaga I extractor kit. All of them are
# REQUIRED: the app bundles carry them, the launchers (launch.command,
# launch.bat, launch.sh) install them when the Python they find lacks any,
# build.py refuses to build without them, and `python cli.py self-test` fails
# (it does not skip) when one cannot be imported. No command falls back to a
# worse path when one is missing.
#
#   python -m pip install -r requirements.txt
#
# Everything else (disc reading, ARX, textures, models, text, write-back) is
# the Python standard library, 3.9 or newer. ffmpeg (movies, FLAC) is a
# program, bundled under tools/ in the app; see packaging/.
#
# The music renderer (ssd_render.py: `cli.py music-export`, WAV/FLAC):
numpy>=1.24
# Required for translations into letters the disc's fonts never had (the
# translation editor's new-script targets, txtarget.py; `cli.py lang scan`,
# statfont, subtitle burning): TrueType outlines and HarfBuzz shaping. The
# launchers install everything in this file when it is missing, and the
# PyInstaller build bundles both.
fonttools>=4.40
uharfbuzz>=0.37
